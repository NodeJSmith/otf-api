## Objectives & Success Criteria

The test infrastructure is in place: respx is a dev dependency, a fixture loader reads anonymized JSON files by name, and a mock client factory produces a fully functional `Otf` instance with auth bypassed, caching disabled, and all 66 fixture routes registered. A single smoke test (`test_smoke.py`) proves the mock client can call one API method and get a parsed Pydantic model back.

## Subtasks

1. Add `respx>=0.21.0` to the `dev` dependency group in `pyproject.toml` and run `uv sync`
2. Create `tests/conftest.py` with:
   - `FIXTURE_DIR` constant pointing to `fixtures/anonymized/`
   - `load_fixture(name: str) -> dict | list` — reads and parses `FIXTURE_DIR/{name}.json`
   - `FIXTURE_INDEX` — loaded once from `fixtures/anonymized/index.json`
   - `MOCK_MEMBER_UUID` constant (use `bdd640fb-0667-4ad1-9c80-317fa3b1799d` — matches fixtures)
3. Create `tests/test_api/__init__.py` (empty)
4. Create `tests/test_api/conftest.py` with a `mock_otf` pytest fixture that:
   - Patches `otf_api.api.client.OtfUser` with a MagicMock (`member_uuid=MOCK_MEMBER_UUID`, `httpx_auth=None`, `cognito_id="mock-cognito-id"`, `email_address="test@example.com"`)
   - Uses `respx.mock` context to intercept HTTP requests
   - Registers routes from `FIXTURE_INDEX` — for each entry, build the full URL from `host + path`, replace known UUIDs as needed, and respond with the fixture's JSON body. Handle query-param disambiguation for endpoints with multiple fixtures on the same path.
   - Patches `otf_api.cache.get_cache` to return a `diskcache.Cache` using a `tmp_path` directory
   - Creates and yields an `Otf(user=mock_user)` instance
5. Write `tests/test_api/test_smoke.py` with one test: `test_get_member_detail` — calls `mock_otf.members.get_member_detail()`, asserts the result is a `MemberDetail` instance with a non-empty `member_uuid` string

## Test Strategy

- `tests/test_api/test_smoke.py::test_get_member_detail` — verifies the full pipeline: fixture loading → route matching → HTTP interception → Pydantic parsing → correct model type returned
- Run with `timeout 300 uv run pytest tests/test_api/test_smoke.py -v`

## Review Guidance

- The `mock_otf` fixture must not import or trigger any Cognito auth code — verify `OtfUser` is fully patched before `Otf()` is instantiated
- Route registration must handle both simple paths and parameterized paths with query strings — verify at least one route with params is registered correctly
- Fixture loading must use paths relative to the repo root, not the test file — verify it works when pytest is run from the repo root
- The diskcache patch must prevent any writes to the user's real cache directory
