- `tests/test_auth/` package exists with shared fixtures in `conftest.py`
- `tests/test_auth/test_utils.py` covers `src/otf_api/auth/utils.py` at 80%+

- All tests pass without `OTF_EMAIL` or `OTF_PASSWORD` set in the environment

## Subtasks

1. Create `tests/test_auth/__init__.py` (empty)
2. Create `tests/test_auth/conftest.py` with shared fixtures:
   - `clean_env` fixture: uses `monkeypatch.delenv` to strip `OTF_EMAIL` and `OTF_PASSWORD`
   - `set_env_creds` fixture: uses `monkeypatch.setenv` to set both to known test values
3. Fix the bare `raise` on `src/otf_api/auth/utils.py:31` — replace with `raise NoCredentialsError("Unable to prompt for credentials in a non-interactive shell")`
4. Test `get_credentials_from_env` — happy path: env vars set → returns `(username, password)` tuple
5. Test `get_credentials_from_env` — missing vars: `OTF_EMAIL` missing, `OTF_PASSWORD` missing, both missing → returns `("", "")`
6. Test `can_provide_input` — patch `os.isatty` to return `True` for both fds → assert `True`; patch to return `False` for stdin → assert `False`
7. Test `get_username_password` — env vars present: with `set_env_creds` active, assert returns expected tuple; patch `_prompt_for_username` to raise to prove it's not called
8. Test `get_username_password` — no env, non-interactive: `clean_env` + patch `can_provide_input` to return `False` → assert raises `NoCredentialsError` (regression test for the bare `raise` fix)
9. Test `_prompt_for_username` — patch `_get_input` to return `""` then valid email → assert returns valid email; patch to return invalid email (no `@`) then valid → assert returns valid
10. Test `_prompt_for_password` — patch `_get_password_input` to return `""` then non-empty → assert returns non-empty

## Test Strategy

All tests in `tests/test_auth/test_utils.py`:

- `test_get_credentials_from_env_present` — verifies happy path returns env values
- `test_get_credentials_from_env_missing_email` — verifies missing OTF_EMAIL returns empty tuple
- `test_get_credentials_from_env_missing_password` — verifies missing OTF_PASSWORD returns empty tuple
- `test_can_provide_input_interactive` — verifies True when both fds are TTY
- `test_can_provide_input_non_interactive` — verifies False when stdin is not TTY
- `test_get_username_password_from_env` — verifies env var path short-circuits before prompting
- `test_get_username_password_no_env_non_interactive` — regression test for bare raise fix
- `test_prompt_for_username_retry_on_empty` — verifies retry loop on empty input
- `test_prompt_for_username_retry_on_invalid_email` — verifies retry on missing `@`
- `test_prompt_for_password_retry_on_empty` — verifies retry loop on empty input

## Review Guidance

- **Bug fix verification**: The bare `raise` on utils.py:31 must be replaced with an explicit `NoCredentialsError`. The regression test must assert `NoCredentialsError` specifically, not a generic exception catch.
- **Environment isolation**: No test should depend on or leak real `OTF_EMAIL`/`OTF_PASSWORD` values. The `clean_env` fixture must strip these before each test.
- **Mock targets**: Interactive I/O functions (`_get_input`, `_get_password_input`) must be patched at their definition location in `otf_api.auth.utils`, not at the call site.
- **No testing of `rich` import path**: The optional `rich` styling is untested by design — testing it adds complexity for minimal coverage gain.
