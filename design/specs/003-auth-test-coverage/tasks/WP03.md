## Review Guidance

- **Fresh instances**: Every test must create a new `OtfCognito` instance to avoid `@property @lru_cache` leaking between tests. Do not reuse instances across tests.
- **PropertyMock for clients**: `idp_client` and `id_client` must be patched via `patch.object(OtfCognito, "idp_client", new_callable=PropertyMock)` — direct attribute assignment won't work because they're `@property @lru_cache` descriptors.
- **verify_token mock**: The mock must mimic real `verify_token` behavior: it sets the token attribute on `self` and populates `id_claims`/`access_claims`. A bare no-op will cause downstream assertions to fail.
- **sleep patch**: The `UserLambdaValidationException` retry test must patch `otf_api.auth.auth.sleep` to avoid a real 5-second delay.
- **Patch targets**: All patches must target the import location in `otf_api.auth.auth`, not the source module (e.g., `otf_api.auth.auth.AWSSRP` not `pycognito.AWSSRP`).
